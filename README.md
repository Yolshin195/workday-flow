# Deep Focus Tracker 🧠🔥

**Deep Focus Tracker** — это одностраничное веб-приложение для осознанной и глубокой работы по методике *Deep Work* (50 минут работы + короткий отдых).

Приложение полностью работает в браузере, не требует регистрации и хранит данные **локально**.

---

## 🚀 Возможности

- ⏱ Таймер глубокой работы и отдыха (работает даже в фоне)
- 🔔 Системные уведомления + звуковой сигнал
- 📊 8 рабочих интервалов в день
- 🟢🟡🔴 Индикатор качества фокуса (по количеству пауз)
- 📝 План задачи и фактический результат для каждого интервала
- 🗓 Фиксация начала и окончания рабочего дня
- 💾 Автосохранение в Local Storage
- 📤 Экспорт и импорт дня в JSON
- 🧪 Демо-режим для быстрого ознакомления

---

## 🛠 Технологии

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **Bootstrap 5**
- **Web Worker** (стабильный таймер)
- **Notification API**
- **Local Storage**

Без фреймворков и сборщиков.
